Windows Guide

The primary platform - everything works out of the box.

← All guides

Standalone executable (recommended)

Grab TS4RLS-windows.exe from the Releases page - no Python install needed. Double-click it to launch the GUI directly; it opens straight to the app with no console window.

Running from source

git clone https://github.com/TS4RLS/Engine.git
cd Engine
pip install -r requirements.txt
python gui.py

Add --generate to run headlessly (one-shot, no GUI) instead - useful for a Steam shortcut or another launcher.

Finding your Mods folder

TS4RLS tries to guess your Sims 4 Mods folder automatically (Documents\Electronic Arts\The Sims 4\Mods) when you first open the Build tab. If it's somewhere else, browse to it manually - it's wherever your game actually reads mods from.

Troubleshooting

  • SmartScreen warning on first run - the executable isn't code-signed. Click More info, then Run anyway.
  • Antivirus flags the .exe - a false positive common with PyInstaller-built executables. Verify you downloaded it from the official Releases page, then add an exclusion if needed.
