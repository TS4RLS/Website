Adding TS4RLS to Steam

Add the TS4RLS executable to your Steam library as a non-Steam game, then apply the artwork below for a native-looking library entry.

  1. 1
    Add the game.

    In Steam: Games → Add a Non-Steam Game to My Library, then browse to TS4RLS.exe.

  2. 2
    Set the artwork.

    In your Library, right-click the new entry → Manage → Set custom artwork, and upload the matching file below for each slot (grid, hero, logo, icon).

For the full walkthrough with screenshots, see this community guide: Adding custom artwork to non-Steam games.
